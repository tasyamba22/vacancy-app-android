# VacancyApp — Android-клиент

Мобильное приложение для поиска вакансий.  
Написано на **Kotlin** с использованием **Jetpack Compose** и **Clean Architecture**.

---

## Стек технологий

| Категория        | Инструмент                                       |
|------------------|--------------------------------------------------|
| Язык             | Kotlin 2.0.21                                    |
| UI               | Jetpack Compose, Material 3                      |
| Навигация        | Navigation Compose                               |
| DI               | Hilt 2.51.1                                      |
| Сеть             | Ktor Client 2.3.12, kotlinx.serialization        |
| Локальная БД     | Room 2.6.1                                       |
| Хранилище        | DataStore Preferences 1.1.1                      |
| Асинхронность    | Kotlin Coroutines + Flow                         |
| Сборка           | Gradle 8.x, KSP, compileSdk 35, minSdk 26       |

## Архитектура

Приложение построено по **Clean Architecture** и разделено на три слоя:

```
presentation/  — Compose UI + ViewModel (MVVM)
domain/        — Use Cases, доменные модели, интерфейсы репозиториев
data/          — Реализации репозиториев, Room (кэш), Ktor Client (сеть), DataStore
```

### Граф зависимостей

```
Composable (UI)
    └── ViewModel
            └── Use Case
                    └── Repository (интерфейс)
                              ├── ApiService  (Ktor → HTTP)
                              ├── VacancyDao  (Room → SQLite)
                              └── DataStore   (токен, история, тема)
```
Приложение использует локальную базу данных Room как основной источник информации о вакансиях.
Пользователь всегда видит данные из этой базы, даже без интернета. Синхронизация с сервером происходит автоматически при открытии списка вакансий.

## Экраны

| Экран             | Описание                                                                       |
|-------------------|--------------------------------------------------------------------------------|
| **Вход**          | Авторизация по email и паролю; JWT сохраняется в DataStore                     |
| **Регистрация**   | Создание аккаунта; пароль от 6 символов                                        |
| **Лента вакансий**| Список всех вакансий с поиском (debounce 300 мс) и фильтрами по городу, компании, зарплате |
| **Мои вакансии**  | Вакансии, созданные текущим пользователем                                      |
| **Добавить / редактировать** | Форма создания и редактирования вакансии                          |
| **Детали вакансии** | Полное описание; для соискателя — кнопка «Откликнуться»; для владельца — редактирование и удаление |
| **Избранное**     | Список вакансий, добавленных в избранное; синхронизируется с сервером          |
| **Резюме**        | Создание, просмотр и редактирование собственного резюме                        |
| **Мои отклики**   | История откликов соискателя со статусами (PENDING / ACCEPTED / REJECTED)       |
| **Отклики на вакансию** | Список откликов для работодателя; смена статуса; просмотр резюме соискателя |
| **Профиль**       | Редактирование имени и фамилии; переключатель тёмной темы; выход из аккаунта  |
| **Админ-панель**  | Список пользователей; блокировка / разблокировка; смена роли; статистика       |

---

## Ролевая модель

| Роль       | Возможности                                                     |
|------------|-----------------------------------------------------------------|
| `USER`     | Поиск вакансий, избранное, резюме, отклики на чужие вакансии,создание, редактирование и удаление своих вакансий, просмотр откликов  |
| `ADMIN`    | Полный доступ: управление пользователями, удаление любых вакансий, статистика |

Роль сохраняется в DataStore после входа и передаётся в `NavGraph` для настройки видимости пунктов меню.
